Fundamentação Teórica sobre Criptoanálise e Wordlists

Conceitos fundamentais de hash, wordlists e repositórios de dados.

O que são Funções Hash?

Uma função hash criptográfica é um algoritmo unidirecional que mapeia dados de tamanho variável em um bloco de tamanho fixo (o hash). Uma alteração mínima nos dados de entrada altera completamente o hash resultante (Efeito Avalanche).

Algoritmo Tamanho (Bits) Tamanho (Hex) Exemplo de Formato e Uso
MD5 128 bits 32 caracteres 098f6bcd4621d373cade4e832627b4f6 (Legado, rápido)
SHA-1 160 bits 40 caracteres a9993e364706816aba3e25717850c26c9cd0d89d (Vulnerável)
SHA-256 256 bits 64 caracteres ba7816bf8f01cfea414140de5dae2223b00361a396... (Padrão atual)
bcrypt Variável (Blowfish) 60 caracteres $2a$12$R9h/cIPz0gi.UR3RYy... (Salt embutido, lento)

Ataque Offline vs. Ataque Online

Ataques Offline consistem em computar hashes localmente a partir de palpites e compará-los com o hash roubado. É extremamente rápido porque não depende da rede. Ataques Online envolvem enviar palpites para um serviço de rede (como uma página web ou SSH). São lentos e propensos a bloqueios (ex: fail2ban).

Localização de Wordlists no Kali Linux

No Kali Linux, a maioria dos dicionários de palavras padrão fica armazenada sob o diretório:

/usr/share/wordlists

Dentro desse diretório, você encontra:

  • rockyou.txt: Wordlist contendo 14.3 milhões de senhas reais vazadas. Vem compactada como rockyou.txt.gz.
  • dirb/ e dirbuster/: Dicionários focados em rotas e arquivos web.
  • seclists/: A coleção definitiva de testes de segurança (se instalada via apt install seclists).

Manual Prático de Sobrevivência: John the Ripper

O John the Ripper é ideal para quebrar arquivos protegidos (ZIP, PDF, RAR, SSH, etc.) convertendo-os em hashes tratáveis.

JOHN

Quebra de Arquivos Protegidos

Converta arquivos criptografados em arquivos de hash compreensíveis pelo John.

⚡ Comandos Úteis
  • zip2john backup.zip > zip.hash: Extrai hash de arquivo ZIP.
  • pdf2john documento.pdf > pdf.hash: Extrai hash de arquivo PDF.
  • ssh2john id_rsa > ssh.hash: Extrai hash de chaves privadas SSH.
  • john --wordlist=/usr/share/wordlists/rockyou.txt zip.hash: Quebra o hash do ZIP.
JOHN CONFIG

Formatos e Regras do John

Opções adicionais do John para acelerar ou personalizar a quebra.

⚡ Comandos Úteis
  • john --list=formats: Lista todos os formatos suportados.
  • john --format=raw-md5 hash.txt: Força formato MD5 cru.
  • john --rules --wordlist=dicio.txt hash.txt: Ativa regras de mangling (mutação).
  • john --show hash.txt: Exibe senhas quebradas anteriormente.

Manual Prático de Sobrevivência: Hashcat

O Hashcat é o quebrador de hashes mais rápido do mundo, otimizado para extrair máxima performance de aceleradoras GPU (placas de vídeo).

MODOS DE ATAQUE

Tipos de Ataque (-a)

Controla a forma como o Hashcat gera palpites de senhas.

⚡ Modos Principais
  • -a 0: Ataque direto por Dicionário (Straight) - Lê palavras da wordlist.
  • -a 1: Combinator - Combina palavras de duas wordlists distintas.
  • -a 3: Mask Attack - Brute force baseado em padrões/máscaras de caracteres.
MODOS DE HASH (-m)

Lista de Modos Comuns

Diz ao Hashcat qual o algoritmo que está sendo quebrado.

⚡ Modos Comuns
  • -m 0: MD5
  • -m 100: SHA-1
  • -m 1000: NTLM (Windows)
  • -m 1400: SHA-256
  • -m 1800: sha512crypt (Debian/Linux default)
  • -m 5600: NetNTLMv2 (Autenticação de Rede Windows)

Exemplo de Comando de Quebra Direta

hashcat -a 0 -m 1400 hashes.txt /usr/share/wordlists/rockyou.txt

Ataques de Força Bruta Online (Hydra & Medusa)

Utilizados para auditar credenciais diretamente contra serviços rodando na rede (portas ativas do laboratório).

HYDRA SSH

Quebra de SSH (Porta 9022)

Realize testes de senhas contra o console SSH simulado na porta 9022.

⚡ Exemplo de Comando
  • hydra -l admin -P /usr/share/wordlists/rockyou.txt ssh://127.0.0.1:9022 -t 4
  • Observe as tentativas incorretas caindo em tempo real na Console de Auditoria!
HYDRA FTP

Quebra de FTP (Porta 9021)

Ataque contra o serviço FTP simulado na porta 9021.

⚡ Exemplo de Comando
  • hydra -l ftp_admin -P /usr/share/wordlists/rockyou.txt ftp://127.0.0.1:9021 -vV
HASH ONLINE

Quebradores de Hash na Web

Plataformas web que consultam bancos de dados gigantescos e rainbow tables para decifrar hashes sem processamento local.

🔗 Principais Ferramentas Online
  • CrackStation: Banco de dados com mais de 15 bilhões de entradas para quebra instantânea de MD5, SHA1, SHA256, etc.
  • MD5Decrypt: Excelente suporte para decifrar hashes MD5, SHA-256, SHA-512 e outros algoritmos comuns.
  • Online Hash Crack: Focado em quebra na nuvem, com suporte para WPA/WPA2, hashes Windows (NTLM) e muito mais.
  • Hashes.com: Ferramenta moderna e eficiente de busca, verificação e quebra de hashes na nuvem.
